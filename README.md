# Weekly VS Score Guide

A compact, mobile-friendly visual reference for **Alliance Competition / VS**: what activities score points on each day.

## View it

Open the GitHub Pages site: **https://jeffxlabs.github.io/zroute-vs-expedition-guide/**

Daily reset is **00:00 server time**.

## Source note

The day/activity map is an interpretation of the Z Route client data v1.30.07, including `AllianceCompetitionStage`, `ActivityTarget`, and `PointSource`. Live event configuration can change, so the in-game event panel remains authoritative.

This is an independent reference and is not affiliated with the game publisher.
